## RecoverFlow

[RecoverFlow](https://recoverflow-ten.vercel.app) helps businesses recover failed payments safely. When a Razorpay payment fails, it works out why and proposes one safe next step; a person approves anything risky, and every decision goes into a tamper-evident log. It runs on Node.js and PostgreSQL, where each webhook is processed exactly once.

## DocuMind

[DocuMind](https://documind-opal-alpha.vercel.app) answers questions about documentation with the exact sentence, highlighted on the original page, or an honest "not in the docs". Its search (BM25 + LSA) is written from scratch.

## CogniSpace

[CogniSpace](https://cognispace-sigma.vercel.app) puts notes and a sprint board in one workspace, with an AI Copilot that edits the page you're on. Built with React, Express, MongoDB and Gemini.
